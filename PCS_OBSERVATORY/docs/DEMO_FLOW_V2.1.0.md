# PCS Observatory v2.1.0 Demo Flow

## Release baseline

- Version: `v2.1.0`
- Status: Stable / Frozen
- Intended audience: researchers, science communicators, educators, and first-time visitors
- Production: <https://uranusastudio-design.github.io/Planetary-common-state/PCS_OBSERVATORY/>
- Next version: `v2.2.0 — Planned`
- Deep Space Phase 4A–4F: planning only; not started

This document is a recording script for the frozen v2.1.0 production release. It
does not start Phase 4, add scientific data, or change the production interface.

## Recording recommendations

- Prefer desktop Chrome at 1280 × 720 or larger and 100% browser zoom. Use 67%
  only when a wider control overview is more important than text size.
- Start from a fresh production tab, wait for the Earth globe and release registry
  to finish loading, then collapse PCS Updates until the closing segment.
- Use Exhibition Scale for the visual overview. Briefly switch to Scientific Scale
  only while explaining the distinction; do not call Exhibition Scale physically
  proportional.
- Use English or Traditional Chinese for the primary recording. Japanese and
  Korean are verified alternatives, but rehearse narration timing after switching.
- Avoid Titania in the primary route. Its imagery coverage / projection issue is a
  deferred known issue, not a completed visual showcase.

## Best concise routes

- Planets: Earth → Mars → Jupiter → Saturn → Neptune.
- Satellites: Moon → Europa → Titan → Triton. The extended option adds Phobos,
  Ganymede, and Enceladus.
- Nearby Stars: 10 pc → Proxima Centauri → Barnard’s Star → 100 pc.
- Phase 3: Milky Way → Galactic Center / Sagittarius A* → Magellanic System →
  Local Group → M31 → M33.

## Mobile limitations

The 390 × 844 production checks passed for reachability, close/return controls,
search, and horizontal layout. Mobile is suitable for a short interactive
demonstration, but it is not the preferred recording surface because dense labels,
long information cards, and the Release Center require more scrolling. Use a
desktop recording for the 2- and 3-minute scripts. Pinch and touch navigation are
available through the existing Cesium controls; rehearse them on the actual device
because headless device emulation does not measure gesture comfort.

## Known issues and deferred items

- Titania imagery coverage / projection remains a deferred known issue; do not use
  it in the primary showcase or describe its visual result as complete.
- Cold-start offline operation still depends on the Cesium CDN. Offline-after-load
  fallback is available for the documented Deep Space data.
- Live regional providers can load at different speeds. Wait once, then use the
  fallback actions above rather than repeatedly toggling controls.
- Phase 4A–4F, comets, asteroids, spacecraft paths, orbit-uncertainty bands, and
  civilization analysis are outside this demo.

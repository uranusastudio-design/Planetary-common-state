## PCS Deep Space — Full-Orbit View / Display Scaling Upgrade

本項工作從 Phase 4E freeze commit `4426a4a` 建立隔離 branch／worktree，避免混入原工作樹尚未完成的 Phase 4F 修改。範圍僅限 Deep Space camera、orbit framing、navigation controls 與 responsive layout；未修改 PCS 核心模型、`L(t)`、五殘差、Earth Viewer 或 frozen v2.1.0 功能，也未啟動 v2.2.0。

### 實作

- 新增七層 Astronomical Camera Scale：Planetary、Inner Solar System、Solar System、Comet Orbit、Heliosphere、Interstellar、Galactic。
- 新增通用 `fitOrbit(object)`，由完整 source-element orbit 的 bounding sphere、orbit plane、實際 FOV、canvas aspect ratio 與 1.28 fit factor 計算 camera；沒有 Halley-specific camera hack 或解析度 preset。
- `sampleFullOrbit()` 以 eccentric anomaly 0 → 2π 建立 361 點閉合路徑；資料來自已部署 NASA/JPL SBDB osculating elements，明列為 catalog-element visualization，不描述成 time-resolved numerical ephemeris。
- FIT ORBIT 使用 cubic easing，動態設定 near／far clipping 與 maximum zoom distance；orbit polyline 使用相對日心場景座標及 `ArcType.NONE`。
- 新增 Camera History；空白 space 或 Back 回復選取前 camera／frustum／selection state，不寫死返回 Sun。
- 既有搜尋支援 `Halley`／`1P/Halley`，Unified Object Card 顯示四語 FIT ORBIT；Viewer、Cesium canvas、renderer、selection、search、Object Card 與 language system 均保持單一實例。
- Desktop viewer 明確扣除可見右側 panel；390×844 mobile viewer 明確扣除底部 Object Card，避免面板遮住完整軌道。

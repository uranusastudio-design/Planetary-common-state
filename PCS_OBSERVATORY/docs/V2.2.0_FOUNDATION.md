# PCS Observatory v2.2.0 Foundation

Status: **In Development**

Stable baseline: **v2.1.0 — Stable / Frozen**

Authorized sequence:

1. Orbit Precision
2. Pointer-Anchored Navigation
3. Unified Object Cards
4. Foundation Integration Audit
5. Foundation Release Audit

Deep Space Phase 4A–4F remains planning only. SITE, Titania surface imagery, comets, asteroids, spacecraft paths, orbit uncertainty bands, civilization analysis, and the formal demonstration video are excluded.

All modules must reuse the existing Cesium Viewer, `scaleContext`, language state, selected-object state, lifecycle, error handling, and reduced mode. No second Viewer, renderer, state machine, permanent animation loop, or live catalog dependency may be introduced.

Completion is not asserted until all three modules, integration audit, production deployment verification, and Foundation Release Audit pass.

## Integration acceptance contract

The Foundation integration audit must run against one deployed commit and verify:

- one Cesium Viewer, one Cesium canvas, and a stable total canvas count;
- 20 Deep Space close/open cycles;
- 30 object selections and 30 orbit switches;
- 50 bounded pointer-zoom input sequences;
- desktop layout at 100%, 67%, 50%, and 33%;
- mobile layout at 390 × 844;
- runtime language switching in Traditional Chinese, English, Japanese, and Korean;
- zero production console exceptions and zero required network failures;
- unchanged Phase 1–3 scientific catalogs and unchanged Titania assets.

Heap observations are comparative evidence only. A single before/after sample is not proof of zero memory leakage.

## Audit state — 2026-08-02

Orbit Precision, Pointer-Anchored Navigation, and Unified Object Cards are functionally complete. Automated production integration passed at commit `6f219b67ff3579b39b347ad90e3ae5f3b51c358c`, including the required lifecycle counts, four desktop zoom levels, the 390 × 844 emulated viewport, four-language runtime state, one Viewer / one Cesium canvas, and zero console or required network failures.

The Foundation Release Audit remains open because physical Mac trackpad pinch and real-device mobile pinch have not been observed in this environment. Synthetic browser events verified the implemented gesture paths but are not recorded as hardware acceptance. See `FOUNDATION_RELEASE_AUDIT_V2.2.0.md`.
